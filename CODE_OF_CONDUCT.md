Standards for participation in the ROSS‑OS Constitutional Substrate project
The ROSS‑OS Constitutional Substrate defines the deterministic kernel that underpins Ross‑OS, CopWan Ledger Physics, Trinity Prism, Everlight 24, and all Ross‑native systems.
Because this repository forms the constitutional foundation of the entire ecosystem, we expect all contributors and participants to uphold a high standard of professionalism, clarity, and respect.

This Code of Conduct outlines the behaviours that maintain a safe, collaborative, and productive environment for everyone involved.

1. Our Commitment
We commit to providing a welcoming, harassment‑free experience for all contributors, regardless of:

technical background

identity or personal characteristics

experience level

geographic location

communication style

We aim to foster an environment where contributors feel supported, respected, and able to focus on building deterministic, high‑integrity systems.

2. Expected Behaviour
Participants are expected to:

communicate with clarity, respect, and professionalism

provide constructive feedback grounded in technical reasoning

uphold the deterministic principles of the substrate

collaborate in good faith

respect differing viewpoints and approaches

follow the contribution guidelines in CONTRIBUTING.md

3. Unacceptable Behaviour
The following behaviours are not tolerated:

harassment, discrimination, or personal attacks

dismissive or hostile communication

introducing nondeterministic, unsafe, or destabilising changes without review

intentionally derailing discussions or PRs

violating the project’s governance or architectural boundaries

4. Reporting Issues
If you experience or witness behaviour that violates this Code of Conduct, please report it via:

Submit a conduct report

Request moderator review

Reports will be handled confidentially and respectfully.

5. Enforcement
Project maintainers will:

review all reports

take appropriate action (warnings, PR rejections, temporary or permanent bans)

ensure decisions are fair, consistent, and aligned with the project’s values

Maintainers must also follow this Code of Conduct. Violations by maintainers will be addressed with equal seriousness.

6. Scope
This Code of Conduct applies to:

all project spaces (GitHub issues, PRs, discussions)

community channels

direct interactions related to the project

any context where a contributor represents the project

7. Our Goal
The ROSS‑OS Constitutional Substrate is a precision‑engineered foundation.
Maintaining a respectful, collaborative environment ensures we can continue building deterministic, replay‑safe, high‑integrity systems together.
